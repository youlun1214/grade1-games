## 四、課綱依據（十二年國教）

### 國語文：注音符號
| 代碼 | 內容 |
|---|---|
| Aa-I-1 | 聲符、韻符、介符的正確發音和寫法 |
| Aa-I-2 | 聲調及其正確的標注方式 |
| Aa-I-3 | 二拼音和三拼音的拼讀和書寫 |
| Aa-I-4 | 結合韻的拼讀和書寫 |
| Aa-I-5 | 標注注音符號的各類文本 |
| 3-I-1（學習表現） | 正確認念、拼讀及書寫注音符號 |

### 數學
| 代碼 | 內容 |
|---|---|
| N-1-1 | 一百以內的數：用數表示多少與順序，位值「個」和「十」，認識 0 |
| N-1-2 | 加法和減法的意義與應用：添加型、併加型、拿走型、比較型 |
| N-1-3 | 基本加減法：1 到 10 之數的加法，及反向的減法 |
| N-1-5 / S-1-1 | 長度：直接比較、間接比較 |
| S-1-2 | 形體的操作：描繪、複製、拼貼、堆疊 |
| N-1-6 | 日常時間用語 |

## 五、多元評量題型 → 遊戲題型

### 注音題型（注音打怪獸）
| 題型 | 例子 | 對應能力 |
|---|---|---|
| 聽音找圖 | 畫面顯示 ㄇ，唸出「貓、筆、豹、跑」→ 哪一個有 ㄇ 的音？ | 符號與發音對應（聽辨） |
| 看圖找第一個音 | 🐱 貓 的第一個音？ | 聲符辨識 |
| 看圖選注音 | 🐱 → ㄇㄠ | 拼讀（認讀） |
| 看注音選圖 | ㄇㄠ → 🐱 | 拼讀（反向） |
| 缺了哪個符號 | ？ㄡˇ 是狗 → ㄍ | 拼音組合 |
| 第幾聲 | 🐴 馬 是第幾聲？ | 聲調 |
| 拼拼看 | ㄏ＋ㄨ＋ㄚ → 🌸 | 三拼音 |

### 數學題型（之後做數學關卡用，依翰林單元）
| 題型 | 例子 | 對應單元 |
|---|---|---|
| 數數量 | 有幾顆 🍎？ | 10 以內的數 |
| 比長短 | 哪一條比較長？ | 比長短 |
| 第幾個／比多少 | 從左邊數來第 3 個是誰？哪邊比較多？ | 順序與多少 |
| 分與合 | 7 可以分成 3 和？ | 分與合 |
| 形狀 | 哪一個是圓形？ | 認識形狀 |
| 加減應用 | 合起來、剩下、多多少 | 10 以內的加法、減法 |
| 30 以內的數 | 2 個十和 4 個一是多少？ | 30 以內的數 |
| 時間 | 幾點鐘？ | 時間 |
