## 一、這是什麼遊戲

- 給 **6～7 歲小學一年級生**玩的學習遊戲，在**平板瀏覽器**上玩
- 有兩個遊戲：**注音打怪獸**（練注音符號）、**數學打怪獸**（練 10 以內的數與加減）
- 玩法：孩子答對題目，就由「光之戰士」攻擊怪獸；答錯或拖太久，怪獸會反擊。**一關一隻怪獸，共 10 關**，越後面的怪獸越強，第 10 關是魔王
- 戰鬥畫面參考 **Game Boy 時代的寶可夢戰鬥畫面**：怪獸在畫面**右上**、玩家在**左下**，兩邊面對面

- 角色在畫面上大約顯示 **130～170 像素高**（平板），所以造型要**簡單、輪廓清楚**，縮小後還認得出是哪一隻

## 二、整體風格：Q 版奧特曼特攝風

| 項目 | 要求 |
|---|---|
| 主題 | **奧特曼（超人力霸王）特攝風格**：光之戰士 vs. 巨大怪獸、宇宙人 |
| 比例 | **Q 版（SD）**：大頭、短手短腳、約 2～2.5 頭身，像扭蛋公仔或 Q 版軟膠玩具 |
| 質感 | 有一點**軟膠玩具／特攝布偶裝**的立體感：明暗分明、表面有鱗片、凹凸紋理或金屬光澤 |
| 線條 | 清楚的**深色粗外框線**（約 4～6 px），縮小後輪廓仍然清楚 |
| 顏色 | 鮮豔、對比強；每隻怪獸保留牠原本的**代表色**，彼此好分辨 |
| 表情與姿勢 | **有氣勢的戰鬥姿勢**（張牙舞爪、舉起鉗子、吼叫），但臉是 Q 版的，**兇得可愛、不可怕** |
| 強弱感 | 第 1 關最小最弱（像寶寶），越後面越大、越威風；第 10 關魔王最霸氣 |
| 禁止 | 血腥、恐怖、寫實嚇人的牙齒眼睛；文字、數字、注音、logo、浮水印、邊框、背景、地面、影子 |

## 三、繪圖規格（每張都要遵守）

| 項目 | 規格 |
|---|---|
| 格式 | **PNG，透明背景**（真正的透明，不是白底或棋盤格圖案） |
| 尺寸 | 正方形，1024×1024 |
| 構圖 | **全身**、置中、角色**盡量填滿畫面**（上下左右留約 5% 空白），**腳底貼近畫面下緣** |
| 方向 | 怪獸 **面向左邊**（看著玩家）；玩家 **面向右邊**（看著怪獸） |
| 數量 | **一張圖只畫一個角色、一種狀態**（不要把三種狀態畫在同一張） |
| 一致性 | 同一隻怪獸的 3 種狀態，**外型、顏色、比例要完全一樣**，只改表情和姿勢 |

### 每隻怪獸要 3 種狀態
| 狀態 | 檔名結尾 | 畫什麼 |
|---|---|---|
| 平常 | `monster-01.png` | 戰鬥姿勢、準備出招，略帶挑釁的表情 |
| 被打到 | `monster-01-hurt.png` | 同樣角度，被光線擊中的樣子：身體往後仰、眼睛變成 > < 、身上冒出小火花或星星 |
| 被打倒 | `monster-01-down.png` | 往後倒地、眼睛變成 @ @ 或 × ×、頭上轉圈的小星星，**看起來是暈倒，不是受傷流血** |

### 玩家角色：小朋友變身「光之戰士」
| 檔名 | 狀態 | 畫什麼 |
|---|---|---|
| `player.png` | 平常 | 站好、雙手擺出戰鬥架式、充滿自信的笑臉，面向右邊 |
| `player-attack.png` | 攻擊 | **雙手交叉成十字發射光線**（奧特曼經典姿勢），手前方有一道藍白色光束 |
| `player-hurt.png` | 被打到 | 往後退一步、單膝微彎、閉眼皺眉，**胸前的能量燈變成紅色閃爍**，不要看起來痛苦 |

- 7 歲男孩、Q 版二頭身，穿著**奧特戰士風格的戰鬥服**：銀色為底、**紅色線條**、**胸前一顆藍色發光的能量燈（彩色計時器）**
- **臉要露出來**（像戴著打開面罩的頭盔，或頭上戴奧特曼造型的頭盔、臉露在外面），這樣孩子看得出是自己
- 若有提供參考照片，只參考**髮型、臉型、膚色等大致特徵**，畫成卡通人物即可，**不要畫得像照片本人**

### 戰鬥背景（選擇性）
| 檔名 | 規格 |
|---|---|
| `battle.jpg` | 橫向 1280×800、JPG；**特攝感的戰場**：遠方的城市剪影或山脈、黃昏天空，地面是空曠的荒地或採石場；**中間不要有東西**（角色會站在上面），顏色淡一點才不會搶走角色 |

## 五、建議的產圖順序

1. 先畫 **`monster-01`（卡內貢）平常狀態**，確認畫風 → 這張就是之後所有角色的**風格基準**
2. 用同樣風格畫 `monster-01-hurt`、`monster-01-down`
3. 依序畫 `monster-02` ～ `monster-10`（每隻都是 平常 → 被打到 → 被打倒）
4. 畫玩家 `player` 三張
5. 最後畫背景 `battle.jpg`

每畫完一張，請在回覆中寫出**檔名**（例如 `monster-03-hurt.png`），方便我下載後直接改名。
