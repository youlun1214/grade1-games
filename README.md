# grade1-games

2026 小一互動遊戲工作坊 — 給小一新生玩的 **數學遊戲** 與 **注音符號對戰遊戲** 合集。

網站：https://youlun1214.github.io/grade1-games/

## 結構
- `index.html`：首頁，串起所有遊戲
- `tools/<遊戲名>/`：每個遊戲一個子資料夾（數學 `math-*`、注音 `zhuyin-*`）
- `shared/`：共用程式（打怪獸對戰引擎、音效）
- `assets/`：共用圖片（怪獸、玩家角色、背景）
- `docs/battle-rules.md`：對戰規則
